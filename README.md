🎯 Activity Selector
A lightweight web application designed to help users overcome indecision by randomly selecting daily activities. Users can also dynamically expand the activity pool by adding their own suggestions.
--------------------------------------------------------------------------------
✨ Features
Random Selection: Instantly picks a random task from a predefined list.

Dynamic Update: Allows users to input and add new activities to the session list.

Clean UI: Features a vibrant, centered design with smooth linear gradients and custom typography.
------------------------------------------------------------------------------------
🛠️ Tech Stack
HTML5: Structured the interactive elements and input fields.

CSS3: Styled with flexbox, Google fonts, and linear gradients for a modern look.

JavaScript (ES6): Handled the logic for random index generation and DOM manipulation
